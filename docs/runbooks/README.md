# Runbooks

Operational playbooks. One file per scenario.

## Index

| Runbook | Purpose |
|---|---|
| [`getting-started.md`](./getting-started.md) | Local development bring-up — services, ports, seeded credentials, verification checklist, troubleshooting. |

## Conventions

- Lead with **symptoms** so anyone scanning a page can confirm they're in the right runbook.
- Then **diagnosis** steps (commands to run, dashboards to check).
- Then **remediation** steps in the order they should be tried.
- End with **postmortem checklist** items if the incident warrants one.
