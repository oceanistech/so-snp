# BRD mirror

This folder holds a **read-only mirror** of the canonical platform BRD.

| File | Purpose |
|---|---|
| `platform-brd.md` | Mirror of `../../../platform-brd.md` (canonical source). |
| `platform-brd.html` | Mirror of `../../../platform-brd.html` (rendered). |

## Source of truth

The canonical files live at the **repository root** of `shipinvest/`:

```
shipinvest/
├── platform-brd.md     <-- edit here
├── platform-brd.html   <-- regenerated by build-brd-html.sh
└── web/docs/brd/       <-- mirrored copy (this folder)
```

## Update procedure

Any change to the BRD MUST follow this order, in a single commit:

1. Edit `shipinvest/platform-brd.md`.
2. Run `bash build-brd-html.sh` from the `shipinvest/` root to regenerate `platform-brd.html`.
3. Copy both files into this folder, overwriting:

   ```bash
   cp ../../../platform-brd.md   ./platform-brd.md
   cp ../../../platform-brd.html ./platform-brd.html
   ```

4. Commit all four touched files (`platform-brd.md`, `platform-brd.html`,
   `web/docs/brd/platform-brd.md`, `web/docs/brd/platform-brd.html`)
   together.

Reference: see `§2.5 Document Maintenance` inside `platform-brd.md` itself.
